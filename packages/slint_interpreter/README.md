# slint_interpreter

Slint runtime for Flutter via Rust FFI — `slint-interpreter` plus the
software renderer. Provides `SlintInterpreterFactory` for the typed wrappers
from `slint_generator`, and runtime compile via `SlintComponent.loadAsset`.

```yaml
dependencies:
  slint_interpreter: ^0.0.1
```

**Full docs:** see the docs site (`just docs-serve`) — package page under
Packages, and the [Backends](../../site/content/guides/backends.md) guide.
