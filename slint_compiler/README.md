# slint_compiler

Compile-time Slint path for Flutter — typed components generated by `slint-build`, no interpreter.

## What it is

This package is both a complete example and a pattern for integrating Slint's compile-time path into Flutter apps:

- **No interpreter**: Components are compiled to Rust at build time via `slint-build`. Each generated component gets its own typed FFI surface.
- **Per-component pattern**: This crate (`slint_compiler/rust`) compiles a todo.slint demo. Apps extend it: drop a new .slint file, update build.rs, and regenerate the C header. The Dart side (lib/src/compiled_todo_app.dart) becomes a template — rename the class, update property/callback names, and the rest is generated.
- **No reflection**: The compiled path has no Dart getProperty/setProperty dispatch or invokeCallback. Properties are typed at the Slint level; only those named in the generated wrapper are accessible.

## Build

```bash
cd slint_compiler
cargo build -p slint_compiler-ffi --release
dart run ffigen
```

Then run `dart analyze` to verify the generated bindings.

## Example

```dart
import 'package:slint_compiler/slint_compiler.dart';

final app = CompiledTodoApp();
app.renderTarget.resize(800, 600);

// Get/set the todo model (JSON)
final todos = app.getProperty('todo-model');
app.setProperty('todo-model', [
  {'title': 'Learn Slint', 'checked': false},
  {'title': 'Build an app', 'checked': true},
]);

// Register callbacks
app.setCallbackHandler('add-todo', (args) {
  final text = args[0] as String;
  print('Added: $text');
});

app.setCallbackHandler('toggle-todo', (args) {
  final index = args[0] as int;
  final checked = args[1] as bool;
  print('Toggled todo $index to $checked');
});

// Render
if (app.renderTarget.render()) {
  final pixels = app.renderTarget.pixels;
  // Paint pixels to Flutter canvas
}

app.dispose();
```

## Public API

### CompiledTodoApp

- `CompiledTodoApp()` — Create instance; throws StateError on FFI failure.
- `getProperty(String name)` — Get "todo-model" (JSON); throws ArgumentError for unknown names.
- `setProperty(String name, Object? value)` — Set "todo-model"; throws ArgumentError for unknown names.
- `setCallbackHandler(String name, SlintCallbackHandler handler)` — Register handler for "add-todo", "toggle-todo", or "remove-done"; throws ArgumentError for unknown names.
- `invokeCallback(String name, List<Object?> arguments)` — Throws UnsupportedError (compiled path is not interpreted).
- `renderTarget` — _CompiledTodoSoftwareRenderTarget (implements SlintSoftwareRenderTarget); manage resize/render/dispatch events.
- `dispose()` — Free all native resources; idempotent.

## Architecture

- **C boundary**: Rust exports 13 functions in `rust/include/slint_compiler_ffi.h`. `ffigen` generates Dart bindings (`lib/src/bindings.g.dart`).
- **Platform loading**: `lib/src/library.dart` handles dylib discovery (macOS/iOS: .dylib, Windows: .dll, Linux: .so).
- **Component wrapper**: `lib/src/compiled_todo_app.dart` wraps the typed Rust API; NativeCallable.isolateLocal bridges callbacks; Uint8List pixel buffer is allocated/resized on renderTarget.resize().
- **Callback dispatch**: JSON-encoded args cross the FFI boundary; decoded on Dart side and passed to handlers as List<Object?>.
